# AD LAUNCH MAP — АкваСтрой

## Цель
Быстро запускать рекламу не на главную, а на релевантные service pages с самой высокой коммерческой отдачей.

## Приоритет запуска

### Волна 1 — ядро спроса
1. `burenie-skvazhin.html`
   - запросы: бурение скважин, скважина на воду, скважина для дома, скважина для дачи
   - зачем запускать первой: самое широкое и понятное ядро спроса

2. `skvazhina-pod-klyuch.html`
   - запросы: скважина под ключ, вода в дом из скважины, комплексное решение по скважине
   - зачем запускать первой: более тёплый и дорогой спрос, ближе к комплексной сделке

3. `obustroystvo-skvazhin.html`
   - запросы: обустройство скважины, адаптер, кессон, ввод воды в дом
   - зачем запускать первой: частый следующий этап после бурения и отдельный спрос от владельцев существующих скважин

### Волна 2 — проблемный и доукомплектовывающий спрос
4. `vodopodgotovka.html`
   - запросы: вода пахнет, железо в воде, фильтры для скважины, очистка воды в доме
   - зачем запускать второй волной: хороший спрос, но важна более точная сегментация по симптомам

5. `nasosnoe-oborudovanie.html`
   - запросы: насос для скважины, насос для дома, слабое давление, подобрать насос
   - зачем запускать второй волной: спрос есть, но он смешанный — часть людей ищет оборудование, часть решение задачи

6. `remont-nasosov.html`
   - запросы: насос не качает, ремонт насоса, слабое давление, насос часто включается
   - зачем запускать второй волной: узкий, но очень целевой проблемный интент

### Волна 3 — дополнительные направления
7. `avtopoliv.html`
   - запросы: автополив участка, система полива, полив от скважины
   - запускать после ядра, как смежное сезонное направление

8. `otoplenie.html`
   - запросы: отопление дома, монтаж отопления, переделка отопления
   - запускать отдельно от water-кластера, когда появится ресурс на второе смысловое направление

## Правило маршрутизации
- реклама по бурению → `burenie-skvazhin.html`
- реклама по комплексному решению → `skvazhina-pod-klyuch.html`
- реклама по существующей скважине → `obustroystvo-skvazhin.html`
- реклама по качеству воды → `vodopodgotovka.html`
- реклама по насосам → `nasosnoe-oborudovanie.html`
- реклама по поломкам/давлению → `remont-nasosov.html`
- не вести все кампании на `index.html`

## Рекомендуемая структура кампаний

### Кампания 1: Бурение
- группа: бурение скважин
- группа: скважина для дома
- группа: скважина для дачи
- группа: бурение + Казань / пригород

### Кампания 2: Под ключ
- группа: скважина под ключ
- группа: вода в доме из скважины
- группа: комплекс по воде для дома

### Кампания 3: Обустройство
- группа: обустройство скважины
- группа: адаптер / кессон
- группа: ввод воды в дом

### Кампания 4: Водоподготовка
- группа: железо в воде
- группа: запах воды
- группа: фильтр для скважины
- группа: очистка воды для дома

### Кампания 5: Насосы и ремонт
- группа: насос для скважины
- группа: слабое давление
- группа: насос не качает
- группа: ремонт насоса

## Что важно перед запуском
- подставить реальный телефон
- включить Telegram в production-режим
- подключить Метрику
- завести отдельные UTM-метки по каждому направлению
- не смешивать в одном объявлении разные услуги без явного общего интента
