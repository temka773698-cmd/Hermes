# MVP site prototype: Telegram lead intake

## Что уже сделано
- многостраничный сайт с отдельными посадочными под услуги
- общая навигация
- MVP-калькулятор на главной
- формы заявок на каждой странице
- backend `/api/lead`, который умеет:
  - показывать предпросмотр заявки
  - отправлять заявку в Telegram, если заполнены переменные окружения

## Файлы
- `index.html` — главная
- `*.html` — страницы услуг
- `style.css` — стили
- `app.js` — фронтенд логика форм
- `server.py` — локальный сервер + API для заявок
- `.env.example` — пример настроек

## Запуск
```bash
cd /home/art/04_ai_agents/kazan_well_marketing/prototype
cp .env.example .env
python3 server.py
```

После запуска:
- сайт: `http://127.0.0.1:8765/index.html`
- формы стучатся в `POST /api/lead`

## Telegram
Чтобы заявки реально улетали в Telegram, в `.env` нужно заполнить:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Если они пустые, сайт работает в режиме preview и просто показывает готовое сообщение заявки.

## Формат заявки
В Telegram отправляется сообщение вида:
- сайт
- имя
- телефон
- населённый пункт
- что нужно
- комментарий
- страница
- источник
