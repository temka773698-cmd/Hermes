# Pump Web Agent

Локальный MVP web-агента для сбора заявок на насосное оборудование.

## Что уже умеет

- показывает простую страницу с чатом;
- ведёт первичный диалог по насосному оборудованию;
- обязательно спрашивает:
  - нужен только насос или полный комплект;
  - нужна ли водоочистка / есть ли анализ воды;
- не делает обязательными вопросы бюджета, срочности и желаемого давления;
- сохраняет готовые заявки в `data/leads.jsonl`;
- при наличии настроек отправляет заявку в Telegram-группу.

## Быстрый запуск

```bash
cd /home/art/04_ai_agents/pump_web_agent
python app.py
```

Открыть в браузере:

```text
http://127.0.0.1:8080
```

## Telegram-группа

1. Создать бота через `@BotFather`.
2. Добавить бота в нужную группу.
3. Узнать `chat_id` группы. Часто он выглядит как `-1001234567890`.
4. Создать файл `.env` по примеру `.env.example` или запустить так:

```bash
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export TELEGRAM_GROUP_CHAT_ID="-1001234567890"
python app.py
```

Если переменные не указаны, агент всё равно работает локально, но заявки только сохраняются в файл.

## Структура

```text
agent.py                 # логика диалога и сбор фактов
app.py                   # локальный web-сервер и API
telegram_notify.py       # отправка заявки в Telegram
prompt.md                # бизнес-правила агента
public/index.html        # страница чата
public/style.css         # оформление
public/script.js         # фронтенд-логика
tests/                   # автотесты
```

## Важно

Это MVP без настоящей LLM-модели. Сейчас логика rule-based, чтобы быстро проверить сценарий и не тратить деньги на API. Следующий этап — подключить LLM и оставить эти правила как системный промпт.
